# Graph Evidence Checklist

Use this checklist before presenting Ontoly graph answers:

1. Confirm the graph belongs to the repository under discussion.
2. Confirm diagnostics do not contain blocking parser, validation, or serialization failures.
3. Confirm the question's concept type is represented in the graph.
4. Confirm relationships have direction, type, provenance, and source locations.
5. Confirm ambiguous node names are resolved by module, package, route, or file path.
6. Confirm confidence is derived from graph evidence, not model intuition.

If any check fails, report the limitation and either ask for clarification or perform narrow source verification.
