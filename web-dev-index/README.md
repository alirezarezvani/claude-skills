# Upstream web-development skills index

This folder tracks the **web-development-related skills** referenced by the upstream repository:

- Source: <https://github.com/travisvn/awesome-claude-skills>

## Why this is an index and not a direct import

The upstream repository currently exposes no declared license in the repository metadata or root tree. Because of that, this repo does **not** vendor or copy the upstream skill contents here.

Instead, this folder provides a dedicated local index of the relevant upstream skills so they can be reviewed, referenced, and manually imported later if the upstream project adds a license or explicit reuse permission.

## Import policy for this repo

If you want these skills fully vendored here later, first verify one of the following:

1. the upstream repository adds a license that permits reuse, or
2. the upstream author grants explicit permission for redistribution

Until then, this folder should remain an **upstream reference index**, not a copied skill bundle.
