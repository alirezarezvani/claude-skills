# Jarvis Brain

Persistent knowledge index for **lordhammer11** — one source of truth for every project, formula, skill, and idea across all repos. Query with `/brain` in Claude Code. Syncs daily via GitHub Actions.

---

## File Structure

| File | Purpose |
|------|---------|
| `brain/index.json` | **Source of truth.** All entries and ideas in JSON. |
| `brain/timeline.md` | Chronological view, newest first. |
| `brain/entries/` | Per-entry markdown files (reserved for rich detail). |
| `BRAIN.md` | Human-readable dashboard; auto-regenerated by `brain_update.py`. |
| `.claude/commands/brain.md` | `/brain` slash command — teaches Claude the full schema and workflows. |
| `scripts/brain_update.py` | CLI sync: pulls live PR statuses from GitHub, rebuilds `BRAIN.md`. |
| `.github/workflows/brain-sync.yml` | Runs `brain_update.py` daily at 06:00 UTC and on every push to `main`. |

---

## Using `/brain` in Claude Code

```
/brain                                   # Overview dashboard
/brain what have I built?                # Summarise all entries
/brain search macos                      # Entries tagged 'macos'
/brain add idea: Raycast extension       # Add to ideas backlog
/brain status gemma3-metal-macos active  # Change entry status
/brain archive apex-agent               # Archive an entry
/brain show ideas                        # List the ideas backlog
```

Claude reads `brain/index.json`, answers, and writes changes back to both `index.json` and `BRAIN.md`. After each edit it prints the exact `git commit` command to run.

---

## Running `brain_update.py`

```bash
pip install requests                                             # one-time

python3 scripts/brain_update.py --token $GITHUB_TOKEN           # full sync
python3 scripts/brain_update.py --rebuild-md                    # BRAIN.md only
python3 scripts/brain_update.py --token $GITHUB_TOKEN --dry-run # preview only
```

```bash
python3 -m http.server 8080 --directory brain/

```
