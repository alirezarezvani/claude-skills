# panroot-web-dev

Premium website development skill for Panroot Security Ghana. Benchmarks against igloo.inc, Ring, ADT, Vivint.

**Tech:** Next.js 14 · Tailwind CSS v3 · Framer Motion · GSAP · Three.js · WebGL shaders

**Triggers on:** build website, create website, landing page, web component, frontend, homepage

## Quick Start

```
/cs:web-dev              — activate agent
/cs:web-dev hero         — build hero section immediately
/cs:web-dev services     — build services grid immediately
```

## What's Inside

- `skills/panroot-web-dev/SKILL.md` — full spec: company profile, design system, page architecture, animation playbook
- `skills/panroot-web-dev/references/animation-guide.md` — GSAP, Framer Motion, Three.js patterns with code
- `skills/panroot-web-dev/references/mcp-setup.md` — Figma, 21st.dev, paper.design, stitch setup
- `agents/cs-web-dev.md` — persona agent with context: fork
- `commands/cs-web-dev.md` — `/cs:web-dev` slash command
