# Market Calibration

Default assumptions when the user does not specify a market. Pick the region from the user's own context — language, city, employer location. If none of those settles it, ask once; do not fall back to a fixed region. State the assumed market at the top of the report.

| Dimension | Mainland China | North America | Europe |
|---|---|---|---|
| Currency | ¥ | $ | € |
| Default income target | +¥3,000–8,000 / month | +$500–2,000 / month | +€500–2,000 / month |
| Marketplaces | Xianyu, Xiaohongshu, Zhubajie, Zaihang | Upwork, Fiverr, Etsy, Gumroad | Malt, Fiverr, Etsy |
| Salary references | KanZhun, Maimai, BOSS Zhipin | levels.fyi, Glassdoor, BLS | Glassdoor, StepStone |

## Rules

- **Never mechanically apply the table.** A Chinese-speaking user living in Berlin follows the European marketplaces but keeps Chinese-language channels alongside.
- **Cite the comparator, not the table.** The table only supplies a default range; every number in the report still needs a source or an "unverified estimate" label.
- **State the assumption.** First line of the report: "Assumed market: <region>, based on <evidence>."
- **Currency disclosure.** Convert once, note the rate and date, and do not mix currencies inside one table.

## When search is unavailable

Every range from this table is then an estimate. Write "estimate, unverified — default range for <region>" next to it and list it in Appendix B. Do not present the default range as a market fact.
